# MyResume

MyResume, built with React and TypeScript, bundled with Vite.

## Getting Started

### Clone Repository

`git clone https://github.com/Naturalclar/myResume.git`

### Install Dependencies

`pnpm install`

### Develop with Live Reloading

`pnpm dev`

### Bundle Files

`pnpm build`

### Preview the Production Build

`pnpm start`

### Lint

`pnpm lint`
